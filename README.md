# 🏡 RoadTheDream — Продвинутый ипотечный трекер

**RoadTheDream** — это fullstack веб-приложение для умного управления ипотечными кредитами. Это не просто калькулятор, а полноценный финансовый дневник, который помогает планировать досрочные погашения, визуализировать экономию и вести учет реальных платежей.

## ✨ Ключевые возможности

- 🧮 **Точный расчет:** Поддержка аннуитетных и дифференцированных платежей, расчет с точностью до копейки.
- ⚡ **Умные досрочки:** Внесение разовых или ежемесячных досрочных платежей с выбором стратегии (уменьшение срока или суммы платежа).
- 📊 **А/Б тестирование стратегий:** График одновременно показывает две линии — базовый сценарий и текущий (с досрочками), чтобы визуально оценить «пропасть» сэкономленных денег.
- 🎮 **Геймификация:** Автоматический подсчет сэкономленных лет и миллионов рублей при каждом внесенном платеже.
- ✅ **Трекер платежей (Чек-лист):** Возможность отмечать прошедшие месяцы как «Оплаченные» — интерфейс работает как ваш личный финансовый дневник.
- 📂 **Мульти-кредитность:** Ведение нескольких ипотек или кредитов одновременно с удобным переключением через вкладки.
- 🌙 **Современный UI:** Премиальная темная тема, плавная анимация графиков (Recharts) и адаптивный дизайн.
- 💾 **Надежность:** Все данные надежно сохраняются в базу данных PostgreSQL, а состояние интерфейса кэшируется в браузере.

## 🛠 Стек технологий

**Frontend:**
- React 18 + TypeScript
- Vite (Сборщик)
- Tailwind CSS (Стилизация)
- Recharts (Графики)
- Axios (HTTP-клиент)
- Lucide React (Иконки)

**Backend:**
- Python 3.10+
- FastAPI (REST API)
- SQLAlchemy (ORM)
- Pydantic (Валидация данных)

**Инфраструктура & БД:**
- PostgreSQL 15
- Docker & Docker Compose (Контейнеризация и Volumes для сохранения данных)
